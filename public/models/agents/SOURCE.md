# Raspberry Pi 5 model

`raspberry-pi-5.stl` is an STL export of **Raspberry Pi 5 Model B layout** by
Innerscene, sourced from
https://www.innerscene.com/tools/library/3d-parts/raspberry-pi-5-model-b-layout-e715c5fd.

Innerscene dedicates the original model to the public domain under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/.

The model is a visual reconstruction based on published dimensions. Connector
and component details may be nominal; check a physical board before using it
for manufacturing clearances. The case, cooling and network elements in the
interactive page are Evolve concept visuals, not part of this STL.
