# Prompt Template

## Ruolo

Agisci come agente di coding senior sul repository Evolve.

## Contesto

Descrivi repository, feature, stato attuale e obiettivo.

## Vincoli non negoziabili

Elenca vincoli su rotte, env, privacy, sicurezza, tracking, cleanup e documentazione.

## File da modificare

Elenca path runtime, componenti, API, librerie e documentazione.

## File da eliminare

Elenca rotte obsolete, duplicati e componenti non usati.

## Criteri di accettazione

Elenca comportamento atteso, build, assenza regressioni e verifiche manuali.

## Output finale

Richiedi riepilogo modifiche, file creati/modificati/eliminati, comandi eseguiti, esito test e limitazioni.
