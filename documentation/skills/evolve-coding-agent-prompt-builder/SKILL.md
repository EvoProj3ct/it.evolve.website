# evolve-coding-agent-prompt-builder

## Scopo

Trasformare brainstorming, decisioni tecniche e checklist in prompt completi per agenti di coding.

## Output atteso

- Prompt operativo.
- Contesto repository.
- Vincoli non negoziabili.
- File da modificare.
- File da eliminare.
- Criteri di accettazione.
- Test.
- Rischi.
- Ordine di implementazione.

## Divieti

- Non implementare direttamente.
- Non creare PR.
- Non fare commit.
