# Forms Checklist

- [ ] Il form raccoglie solo dati necessari?
- [ ] Privacy linkata a `/privacy`?
- [ ] Sicurezza linkata a `/sicurezza`?
- [ ] Cookie policy linkata a `/cookie-policy` se pertinente?
- [ ] Consensi facoltativi non preselezionati?
- [ ] Marketing, eventi, prodotti e materiali separati?
- [ ] `sourcePage` valorizzato?
- [ ] `sourceContext` valorizzato?
- [ ] Honeypot presente?
- [ ] Validazione client/server coerente?
- [ ] Duplicate handling presente?
- [ ] Messaggio utente coerente con backend?
