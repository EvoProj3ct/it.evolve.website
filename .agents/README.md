# SMART Agents

Questa cartella contiene le istruzioni operative minime usate in questo repository.

## Skill disponibili

- `smart-step-3-derivation`
- `smart-homepage-fidelity`
- `evolve-coding-agent-prompt-builder`
- `evolve-privacy-compliance-reviewer`
- `evolve-webapp-migration-planner`

## Uso consigliato

1. Applica `smart-homepage-fidelity` per aggiornare homepage e palette senza perdere il layout validato.
2. Applica `smart-step-3-derivation` solo per produrre o rifinire derivati Step 3.
3. Applica `evolve-coding-agent-prompt-builder` per trasformare brainstorming e decisioni in prompt operativi per agenti di coding.
4. Applica `evolve-privacy-compliance-reviewer` per audit privacy/GDPR su rotte, cookie e consensi form.
5. Applica `evolve-webapp-migration-planner` per pianificare migrazioni, refactor e decommissioning senza modificare codice.
6. Mantieni coerenza con i vincoli contenutistici e i report di validazione gia presenti.
