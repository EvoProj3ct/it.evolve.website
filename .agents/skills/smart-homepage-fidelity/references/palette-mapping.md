# Palette Mapping Evolve

## Obiettivo

Inserire il verde Evolve come asse primario mantenendo l'energia del layout Figma.

## Mapping approvato

- `purple-*` -> `emerald-*`
- `blue-*` -> `teal-*`
- `green-*` -> `emerald-*` (uniformazione)
- `pink-*` -> invariato
- `orange-*` -> invariato
- `yellow-*` -> `emerald-*` o `teal-*` a seconda del contesto glow

## Regole applicative

- Almeno un accento `emerald` in ogni macro-sezione.
- Conservare contrasti chiaro/scuro analoghi all'originale.
- Evitare sostituzioni globali cieche: rispettare ruolo semantico del colore (CTA, info-chip, decorazione).
