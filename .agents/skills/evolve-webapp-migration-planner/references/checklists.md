# Migration Planner Checklist

- Identifica source repository e target repository.
- Mappa rotte source -> target.
- Elenca rotte da rimuovere senza redirect.
- Verifica componenti duplicati o obsoleti.
- Verifica API, schema, env e database.
- Verifica asset e path pubblici.
- Verifica documentazione da creare o aggiornare.
- Definisci criteri QA e build.
- Evidenzia rischi e decisioni aperte.
