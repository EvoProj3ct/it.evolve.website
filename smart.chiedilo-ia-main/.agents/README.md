# SMART Agents

Questa cartella contiene le istruzioni operative minime usate in questo repository.

## Skill disponibili

- `smart-step-3-derivation`
- `smart-homepage-fidelity`

## Uso consigliato

1. Apri gli artefatti gia presenti in `bcc-event/`.
2. Applica `smart-step-3-derivation` solo per produrre o rifinire derivati Step 3.
3. Applica `smart-homepage-fidelity` per aggiornare homepage e palette senza perdere il layout validato.
4. Mantieni coerenza con i vincoli contenutistici e i report di validazione gia presenti.

## Regola

Non introdurre claim non supportati e non alterare la tracciabilita degli output.
